# Tukutane Event Listing App

This is a React Native application built for the Tukutane Internship Challenge. The app lists events fetched from **Firebase Firestore**, with options to RSVP, filter by category, and save events to your calendar.

## Features
- Fetches event data from Firebase Firestore
- Displays:
  - Event image
  - Event name
  - Category
  - RSVP button (alerts RSVP action)
  - Save to Calendar button (adds the event to device calendar)
- Filter events by category (e.g., Music, Tech)
- Simple and clean UI for easy browsing

## Bonus Features
- Added category filtering
- Added **Save to Calendar** functionality via `react-native-add-calendar-event`

## Tech Stack
- React Native
- Firebase Firestore
- React Native Firebase
- react-native-add-calendar-event
